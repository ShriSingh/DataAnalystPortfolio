# DataAnalystPortfolio
All the mini projects of me working with data, such as doing exploration, cleaning, analysis, visualizations, and web scraping. I did these using tools like SQL Server, Excel, Python, Power BI, and Tableau.
- **SQL Server**: Conducting data exploration and data cleaning in various datasets and figuring out various insights using SQL scripts
- **Excel**: Doing data cleaning and management to prepare datasets for data analytics and info tables
- **Python**: First making mini projects to sharpen python skills, then conducting web scraping and making informatics through Pandas and Jupyter Notebooks
- **Tableau & Power BI**: Visualizing information in graphs and charts, calculating statistics, and presenting insights through dashboards
